# Fiber torch #

## About ##
Early game or decorative light source.
Break grass while holding flint to obtain plant fibers and craft fiber torches like normal torches but with plant fibers instead of (char)coal.

Mod created for a private mod pack with GregTech CE Unofficial which makes charcoal harder to obtain,
couldn't find any existing mod with easy to obtain early game light source that isn't fully free like Ars Nouveau mage lights are so wrote this mod.

## Building ##

Run data generation with `./gradlew runData`and build the jar with `./gradlew build`

## Supported game versions ##

For now only Forge for Minecraft 1.20.1 is supported.
